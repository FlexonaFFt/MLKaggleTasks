# Блок 0. Описательная статистика

| Что нужно | Код / формула |
|---|---|
| среднее, медиана | `np.mean(x)`, `np.median(x)` |
| стандартное отклонение, дисперсия | `np.std(x, ddof=1)`, `np.var(x, ddof=1)` (**ddof=1** обязательно) |
| квартили, IQR | `q1, q3 = np.percentile(x, [25, 75])`, `iqr = q3 - q1` |
| число интервалов (Стерджесс) | `k = int(np.ceil(1 + np.log2(n)))` (округлять вверх) |
| ширина интервала (Фридман–Дьякони) | `h = 2*iqr / n**(1/3)` |
| границы выбросов | `q1 - 1.5*iqr` и `q3 + 1.5*iqr` |
| выбросы | `x[(x < lower) \| (x > upper)]` (строго вне границ) |

| Картина | Вывод |
|---|---|
| среднее > медиана | хвост вправо, типичное значение — медиана |
| среднее < медиана | хвост влево |
| среднее ≈ медиана | примерно симметрично |

## Форма распределения и сравнение выборок

| Что нужно | Как |
|---|---|
| асимметрия | `stats.skew(x)`: больше 0 — хвост вправо, меньше 0 — влево |
| сравнить две выборки | сравнить среднее, медиану, sd, IQR; можно `plt.boxplot([a, b])` |
| у какой выборки разброс больше | у той, где больше sd (и IQR, если есть выбросы) |
| как выбросы меняют показатели | среднее и sd сильно зависят от выбросов, медиана и IQR почти нет |

# Блок 1. Распределения

## Какое распределение

| Слова в условии | Распределение | scipy | E | Var |
|---|---|---|---|---|
| n независимых опытов, число успехов | Биномиальное | `binom(n, p)` | np | np(1−p) |
| в среднем λ событий за время | Пуассона | `poisson(mu=λ·t)` | λt | λt |
| до первого успеха | Геометрическое | `geom(p)` | 1/p | (1−p)/p² |
| без возвращения из конечной совокупности | Гипергеометрическое | `hypergeom(M, n, N)` | Nn/M | `d.var()` |
| равновероятно на отрезке | Равномерное | `uniform(loc=a, scale=b−a)` | (a+b)/2 | (b−a)²/12 |
| время до следующего события | Экспоненциальное | `expon(scale=1/λ)` | 1/λ | 1/λ² |
| время до k-го события | Гамма | `gamma(a=k, scale=1/λ)` | k/λ | k/λ² |
| «нормально», суммы, ЦПТ | Нормальное | `norm(loc=μ, scale=σ)` | μ | σ² |
| таблица «значение → вероятность» | своё дискретное | через `np` | Σ x·p | Σ x²·p − E² |

## Что спрашивают → метод

| Вопрос | Метод |
|---|---|
| P(X = k) | `d.pmf(k)` |
| P(X ≤ x) | `d.cdf(x)` |
| P(X > x) | `d.sf(x)` |
| x по вероятности q | `d.ppf(q)` (для «больше»: `d.isf(q)`) |
| E, σ | `d.mean()`, `d.std()` |

## Дискретные: слова → код

| Слова | Запись | Код |
|---|---|---|
| не более, ≤ | P(X ≤ k) | `cdf(k)` |
| менее, < | P(X < k) | `cdf(k−1)` |
| более, > | P(X > k) | `sf(k)` |
| не менее, хотя бы, ≥ | P(X ≥ k) | `sf(k−1)` |
| ровно | P(X = k) | `pmf(k)` |

У непрерывных `<` и `≤` одно и то же, `−1` не нужен.

## Поток Пуассона (интенсивность λ)

| Спрашивают | Распределение |
|---|---|
| число событий за t | `poisson(mu=lam*t)` |
| время между событиями | `expon(scale=1/lam)` |
| время до k-го события | `gamma(a=k, scale=1/lam)` |

## Ловушки параметров

| Ловушка | Правило |
|---|---|
| `scale` у expon, gamma | = среднее время = 1/λ |
| `mu` у Пуассона | λ × длина интервала из вопроса |
| `norm` | второй параметр σ, не σ² (N(45, 144) → `scale=12`) |
| `uniform` | второй параметр — ширина, не правая граница |
| `hypergeom` | M всего, n особых, N вытащили |

## Преобразования

| Формула | Условие |
|---|---|
| E[aX + b] = aE[X] + b | всегда |
| Var(aX + b) = a²Var(X) | b исчезает |
| E[X + Y] = E[X] + E[Y] | всегда |
| Var(X + Y) = Var(X) + Var(Y) | только независимые |
| Сумма n одинаковых: E = nμ, Var = nσ² | ЦПТ → нормальное |

## Распределение среднего

| Задача | Решение |
|---|---|
| среднее $n$ независимых одинаковых величин | $\bar X\approx N\!\left(\mu,\ \sigma/\sqrt n\right)$ (ЦПТ), $E[\bar X]=\mu$, $\mathrm{Var}(\bar X)=\sigma^2/n$ |
| $P(\bar X>a)$ | `norm(loc=mu, scale=sigma/np.sqrt(n)).sf(a)` |
| если $X$ нормальна | $\bar X$ нормально точно, при любом $n$ |

## Своё дискретное распределение (таблица «значение → вероятность»)

| Что | Формула | Код |
|---|---|---|
| проверка | $\sum p=1$ | `ps.sum()` |
| математическое ожидание | $E=\sum x\,p$ | `E = (xs*ps).sum()` |
| дисперсия | $\mathrm{Var}=\sum x^2p-E^2$ | `V = (xs**2*ps).sum() - E**2` |
| вероятность события | сложить $p$ нужных значений | `ps[xs >= 2].sum()` |

(`xs`, `ps` — массивы `np.array` значений и вероятностей.)

## Сумма независимых величин

| Задача | Как решать | Код |
|---|---|---|
| сумма $n$ одинаковых независимых | $E=n\mu$, $\mathrm{Var}=n\sigma^2$ (дисперсии складываются, **без** $n^2$) | |
| вероятность для суммы, «с помощью ЦПТ» | $T\approx N(E,\sqrt{\mathrm{Var}})$ | `norm(loc=E, scale=sd).sf(порог)` |
| сумма биномиальных с одинаковым $p$ | снова биномиальное: $\operatorname{Bin}(\sum n_i,\,p)$, можно решить точно | `binom(N, p).sf(k)` |
| биномиальное при большом $n$ (Муавр–Лаплас) | $\operatorname{Bin}(n,p)\approx N(np,\sqrt{np(1-p)})$; поправка на непрерывность: $P(X\le k)\approx\Phi\!\left(\frac{k+0.5-np}{\sqrt{np(1-p)}}\right)$ | `norm(n*p, np.sqrt(n*p*(1-p))).cdf(k + 0.5)` |
| константа $aX$ | $E=aE[X]$, $\mathrm{Var}=a^2\mathrm{Var}(X)$ | |
| порог для «превысит» у дискретного | перевести порог в число событий и взять `sf(k)` | |

Нормальное приближение при большом $n$ даёт ответ, близкий к точному. Если в условии написано «с помощью ЦПТ», берём нормальное.

# Блок 2. Точечные оценки

## Что просят → что делать

| Просят | Алгоритм |
|---|---|
| несмещённость | E[θ̂] = θ ? Смещение = E[θ̂] − θ |
| дисперсия оценки | Var(aX+bY) = a²Var X + b²Var Y |
| ОМП | L (произведение) → ln L → производная = 0 → θ̂ → вторая производная < 0 |
| метод моментов | E[X] = x̄ → выразить θ |
| информация Фишера | ln f → вторая производная по θ → I₁ = −E[ · ] → Iₙ = n·I₁ |
| эффективность | несмещённая и Var(θ̂) = 1/Iₙ |

## Стандартные случаи

| Распределение | ОМП | I₁ | Граница 1/Iₙ |
|---|---|---|---|
| Bernoulli(p) | p̂ = x̄ | 1/(p(1−p)) | p(1−p)/n, x̄ эффективна |
| Poisson(λ) | λ̂ = x̄ | 1/λ | λ/n, x̄ эффективна |
| Exp(λ) | λ̂ = 1/x̄ | 1/λ² | λ²/n |
| N(μ, σ²), σ известна | μ̂ = x̄ | 1/σ² | σ²/n, x̄ эффективна |
| U(0, θ) | θ̂ = max | не применимо | — |

## Линейные оценки

| Оценка | E | Var | Вывод |
|---|---|---|---|
| Σ wᵢXᵢ | μ·Σwᵢ | σ²·Σwᵢ² | несмещена, если Σwᵢ = 1 |
| (2/3)X₁ + (1/3)X₂ | μ | (5/9)σ² | несмещена, но Var > σ²/2 — не эффективна |
| 1/X̄ для Exp(λ) | nλ/(n−1) | — | смещена; несмещённая: (n−1)/Σxᵢ |
| U(0,θ): 2x̄ | θ | — | несмещена |
| U(0,θ): max | nθ/(n+1) | — | смещена; ((n+1)/n)·max несмещена и лучше по MSE |

## Код (sympy)

| Задача | Код |
|---|---|
| ln L | `lnL = S*sp.log(lam) - n*lam` |
| производная | `d1 = sp.diff(lnL, lam)` |
| корень | `sp.solve(sp.Eq(d1, 0), lam)` |
| вторая производная в точке | `sp.diff(lnL, lam, 2).subs(lam, корень)` (меньше 0 → максимум) |
| информация Фишера | `ell = sp.log(lam) - lam*x`; `I1 = sp.simplify(-sp.diff(ell, lam, 2))` |
| численно | `minimize_scalar(lambda t: -d.logpmf(x, t).sum(), bounds=(eps, 1-eps), method="bounded")` |

Свой дискретный закон: через счётчики n₀, n₁, … → L = P(0)^n₀ · P(1)^n₁ · …

## Качество оценок: смещение, MSE, дисперсия, состоятельность

| Что | Формула / правило |
|---|---|
| MSE | $\mathrm{MSE}(\hat\theta)=\mathrm{Var}(\hat\theta)+\mathrm{bias}^2$; у несмещённой MSE = Var |
| какая оценка лучше | та, у которой MSE меньше (смещённая может выиграть у несмещённой) |
| выборочная дисперсия | $S^2=\dfrac1{n-1}\sum(x_i-\bar x)^2$ — **несмещённая**; $\dfrac1n\sum(x_i-\bar x)^2$ смещена: $E=\dfrac{n-1}{n}\sigma^2$ |
| код | `np.var(x, ddof=1)` — несмещённая, `np.var(x)` — смещённая |
| состоятельность | $\hat\theta\to\theta$ при $n\to\infty$; достаточно $\mathrm{bias}\to0$ и $\mathrm{Var}\to0$ |
| $\bar X$ | несмещена, $\mathrm{Var}=\sigma^2/n\to0$, значит состоятельна |

## Правдоподобия для всех распределений

Обозначения: $n$ наблюдений, $S=\sum x_i$.

| Распределение | Одно наблюдение | $L$ | $\ln L$ (без констант) | ОМП |
|---|---|---|---|---|
| Бернулли($p$) | $p^x(1-p)^{1-x}$ | $p^S(1-p)^{n-S}$ | $S\ln p+(n-S)\ln(1-p)$ | $\hat p=S/n=\bar x$ |
| Биномиальное($m,p$), $m$ известно | $\binom mx p^x(1-p)^{m-x}$ | $\propto p^S(1-p)^{nm-S}$ | $S\ln p+(nm-S)\ln(1-p)$ | $\hat p=\dfrac S{nm}$ |
| Пуассона($\lambda$) | $\dfrac{e^{-\lambda}\lambda^x}{x!}$ | $\dfrac{e^{-n\lambda}\lambda^S}{\prod x_i!}$ | $S\ln\lambda-n\lambda$ | $\hat\lambda=\bar x$ |
| Экспоненциальное($\lambda$) | $\lambda e^{-\lambda x}$ | $\lambda^n e^{-\lambda S}$ | $n\ln\lambda-\lambda S$ | $\hat\lambda=1/\bar x$ |
| Геометрическое($p$), число опытов до успеха | $(1-p)^{x-1}p$ | $p^n(1-p)^{S-n}$ | $n\ln p+(S-n)\ln(1-p)$ | $\hat p=n/S=1/\bar x$ |
| Нормальное, $\sigma$ известна | $\dfrac1{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | | $-\dfrac{\sum(x_i-\mu)^2}{2\sigma^2}$ | $\hat\mu=\bar x$ |
| Нормальное, $\mu$ и $\sigma^2$ неизвестны | то же | | $-\dfrac n2\ln\sigma^2-\dfrac{\sum(x_i-\mu)^2}{2\sigma^2}$ | $\hat\mu=\bar x$, $\hat\sigma^2=\dfrac1n\sum(x_i-\bar x)^2$ (смещена) |
| Равномерное $U(0,\theta)$ | $\dfrac1\theta$ при $0\le x\le\theta$ | $\theta^{-n}$ при $\theta\ge\max x_i$, иначе 0 | производная не работает | $\hat\theta=\max x_i$ ($L$ убывает по $\theta$, берём наименьшее допустимое) |
| Своё дискретное | $P(k)$ из условия | $\prod_k P(k)^{n_k}$, $n_k$ — сколько раз встретилось $k$ | $\sum_k n_k\ln P(k)$ | решать $\dfrac{d\ln L}{d\theta}=0$ |

Как собирать $L$ для своего закона: посчитать частоты $n_0,n_1,\dots$ (`np.bincount`), каждую вероятность возвести в степень её частоты.

## Образец: экспоненциальное $\operatorname{Exp}(\lambda)$

| Шаг | Запись |
|---|---|
| плотность одного наблюдения | $f(x)=\lambda e^{-\lambda x}$ |
| правдоподобие | $L=\lambda^n e^{-\lambda S}$, где $S=\sum x_i$ |
| логарифм | $\ln L=n\ln\lambda-\lambda S$ |
| производная | $\dfrac{n}{\lambda}-S=0\;\Rightarrow\;\hat\lambda=\dfrac nS=\dfrac1{\bar x}$ |
| максимум | $\dfrac{d^2\ln L}{d\lambda^2}=-\dfrac n{\lambda^2}<0$ |
| метод моментов | $E[X]=1/\lambda=\bar x\;\Rightarrow\;\hat\lambda=1/\bar x$ (совпадает с ОМП) |
| смещение $1/\bar X$ | $E\!\left[\dfrac1{\bar X}\right]=\dfrac{n\lambda}{n-1}$, смещение $=\dfrac{\lambda}{n-1}>0$ (оценка завышает) |
| несмещённая оценка | $\hat\lambda_{\text{несм}}=\dfrac{n-1}{S}$ |
| Фишер | $\ln f=\ln\lambda-\lambda x$, вторая производная $-\dfrac1{\lambda^2}$, $I_1=\dfrac1{\lambda^2}$, $I_n=\dfrac n{\lambda^2}$ |
| граница Рао–Крамера | $\dfrac{\lambda^2}{n}$ |

| Код | |
|---|---|
| данные | `n = len(x)`, `S = x.sum()` |
| оценка | `lam_hat = n / S` |
| несмещённая | `lam_unb = (n - 1) / S` |
| граница | `lam_hat**2 / n` |

## Ловушки

| Ловушка | Правило |
|---|---|
| в L сумма | L — произведение, сумма только у ln L |
| нет проверки максимума | вторая производная < 0 |
| эффективность = несмещённость | нужно ещё Var = 1/Iₙ |
| Рао–Крамер для U(0,θ) | не работает |
| константа в Var | в квадрате |
| производная по x | нужна по θ |
| ln(1−3θ) | даёт множитель −3 |
| `subs` | `.subs(переменная, значение)`, не выражение |

# Блок 3. Доверительные интервалы и проверка гипотез

## Схема любой задачи на проверку гипотезы

| Шаг | Что делаем |
|---|---|
| 1 | Записать $H_0$ и $H_1$ (двусторонняя $\ne$ или односторонняя $>$, $<$) |
| 2 | Выбрать критерий по таблице ниже |
| 3 | Посчитать SE и статистику: $\dfrac{\text{оценка}-\text{значение при }H_0}{SE}$ |
| 4 | Найти p-value (учесть вид $H_1$) |
| 5 | Сравнить с $\alpha$: $p<\alpha$ → отвергаем $H_0$ |
| 6 | Написать вывод **словами по задаче**, с направлением эффекта |

## Какой критерий

| Что сравниваем | σ известна? | Критерий | SE |
|---|---|---|---|
| среднее с числом $\mu_0$ | да | Z | $\sigma/\sqrt n$ |
| среднее с числом $\mu_0$ | нет (есть только выборка) | t, $df=n-1$ | $s/\sqrt n$, $s$ = `np.std(x, ddof=1)` |
| доля с числом $p_0$ | | Z | $\sqrt{p_0(1-p_0)/n}$ |
| две доли (A/B) | | Z с объединённой долей | $\sqrt{\hat p(1-\hat p)(\frac1{n_A}+\frac1{n_B})}$ |
| два средних, разные группы | | t Уэлча | считает scipy |
| два средних, одни и те же объекты «до и после» | | парный t | считает scipy |

Быстрое правило: **доли → Z**; **среднее, σ дана → Z**; **среднее, σ не дана → t**.

## Гипотезы и p-value

| Вопрос в условии | $H_0$ | $H_1$ | p-value (Z) | p-value (t) |
|---|---|---|---|---|
| «отличается», «изменилось» | $\mu=\mu_0$ | $\mu\ne\mu_0$ | `2*norm.sf(abs(z))` | `2*t.sf(abs(t_stat), df)` |
| «выросло», «превышает», «больше» | $\mu=\mu_0$ | $\mu>\mu_0$ | `norm.sf(z)` | `t.sf(t_stat, df)` |
| «снизилось», «меньше» | $\mu=\mu_0$ | $\mu<\mu_0$ | `norm.cdf(z)` | `t.cdf(t_stat, df)` |

- Для одностороннего теста p-value в 2 раза меньше двустороннего (если знак эффекта совпал с $H_1$).
- Для двух долей и двух средних «$\mu_0$» заменяется на разность: $H_0$: $p_A=p_B$ (разность равна 0).

| Результат | Вывод |
|---|---|
| $p<\alpha$ | $H_0$ отвергаем: различие статистически значимо |
| $p\ge\alpha$ | $H_0$ **не** отвергаем: данных недостаточно (не «доказали равенство») |

## Код: t-тест

| Что | Код |
|---|---|
| вручную | `se = x.std(ddof=1)/np.sqrt(n)`; `t_stat = (x.mean()-mu0)/se`; `p = 2*stats.t.sf(abs(t_stat), n-1)` |
| одна выборка | `stats.ttest_1samp(x, mu0)` (по умолчанию двусторонний) |
| односторонний | `stats.ttest_1samp(x, mu0, alternative="greater")` или `"less"` |
| две независимые | `stats.ttest_ind(a, b, equal_var=False)` |
| парные | `stats.ttest_rel(a, b)` |

## Доверительный интервал

| Для чего | Формула | Код |
|---|---|---|
| среднее, σ известна | $\bar x\pm z_{1-\alpha/2}\cdot\sigma/\sqrt n$ | `norm.interval(0.95, loc=xbar, scale=sigma/np.sqrt(n))` |
| среднее, σ неизвестна | $\bar x\pm t_{1-\alpha/2,\,n-1}\cdot s/\sqrt n$ | `stats.t.interval(0.95, df=n-1, loc=xbar, scale=s/np.sqrt(n))` |
| доля | $\hat p\pm z\sqrt{\hat p(1-\hat p)/n}$ | `norm.interval(0.95, loc=p, scale=np.sqrt(p*(1-p)/n))` |
| разность долей $p_B-p_A$ | $(\hat p_B-\hat p_A)\pm z\sqrt{\frac{\hat p_A(1-\hat p_A)}{n_A}+\frac{\hat p_B(1-\hat p_B)}{n_B}}$ | `norm.interval(0.95, loc=pB-pA, scale=se_diff)` |

| Правило | Пояснение |
|---|---|
| уровень доверия $=1-\alpha$ | 95% ↔ $\alpha=0.05$, 99% ↔ $\alpha=0.01$ |
| выше уровень → шире интервал | запас на случайность растёт |
| больше $n$ → уже интервал | SE уменьшается |
| в ДИ доли берём **свою** долю | объединённая только в тесте двух долей |
| связь с тестом | $\mu_0$ вне $(1-\alpha)$-ДИ ⇔ двусторонний тест отвергает $H_0$ на уровне $\alpha$ |

## Критические значения

| Уровень | 90% | 95% | 99% |
|---|---|---|---|
| двусторонний, $z$ | 1.645 | 1.960 | 2.576 |
| односторонний, $z$ | 1.282 | 1.645 | 2.326 |

Для t значение зависит от $df$ и больше $z$ (при малом $n$ заметно): `stats.t.ppf(0.975, df)`.

## Тест двух долей (A/B): порядок

| Шаг | Формула | Код |
|---|---|---|
| конверсии | $\hat p=k/n$ | `pA = kA/nA`, `pB = kB/nB` |
| эффект, п.п. | $(\hat p_B-\hat p_A)\cdot100$ | `(pB-pA)*100` |
| относительный прирост, % | $(\hat p_B/\hat p_A-1)\cdot100$ | `(pB/pA-1)*100` |
| объединённая доля | $\hat p=\dfrac{k_A+k_B}{n_A+n_B}$ | `p_pool = (kA+kB)/(nA+nB)` |
| SE теста | $\sqrt{\hat p(1-\hat p)(\frac1{n_A}+\frac1{n_B})}$ | `np.sqrt(p_pool*(1-p_pool)*(1/nA+1/nB))` |
| $z$ | $(\hat p_B-\hat p_A)/SE$ | `z = (pB-pA)/se` |
| p-value | | `2*norm.sf(abs(z))` |

## Ошибки и мощность

| Понятие | Смысл |
|---|---|
| ошибка I рода | отвергли верную $H_0$ («ложная тревога»), вероятность $=\alpha$ |
| ошибка II рода | не заметили реальный эффект, вероятность $=\beta$ |
| мощность | $1-\beta$: вероятность заметить реальный эффект (обычно 0.8) |

| Что делает мощность выше | |
|---|---|
| больше $n$ | да |
| больше эффект | да |
| больше $\alpha$ | да (но больше ложных тревог) |
| меньше разброс | да |

## Размер выборки и MDE

| Случай | $n$ | Код |
|---|---|---|
| две доли, равные группы | $n=\dfrac{2z^2\,p(1-p)}{\delta^2}$ на группу | `int(np.ceil(2*z**2*p*(1-p)/delta**2))` |
| одно среднее | $n=\dfrac{z^2\sigma^2}{\delta^2}$ | `int(np.ceil((z*sigma/delta)**2))` |
| два средних, равные группы | $n=\dfrac{2z^2\sigma^2}{\delta^2}$ на группу | `int(np.ceil(2*(z*sigma/delta)**2))` |

Здесь $z=z_{1-\alpha/2}+z_{\text{мощность}}$: `z = norm.ppf(0.975) + norm.ppf(0.8)` (1.96 + 0.84 = 2.80).

| Что найти | Формула (доли) |
|---|---|
| MDE при данном $n$ | $\sqrt{\dfrac{2z^2\,p(1-p)}{n}}$ |
| всего участников | $2n$ |

| Зависимость | Эффект |
|---|---|
| $\delta$ меньше в 2 раза | $n$ больше в **4 раза** ($n\sim1/\delta^2$) |
| $n$ больше в 4 раза | MDE меньше в 2 раза |
| мощность или $1-\alpha$ выше | $z$ и $n$ растут |
| $p$ ближе к 0.5 | $p(1-p)$ и $n$ растут |

## Дополнительно (если было на лекциях)

| Что | Формула | Код |
|---|---|---|
| ДИ для дисперсии (нормальные данные) | $\left(\dfrac{(n-1)s^2}{\chi^2_{1-\alpha/2}},\ \dfrac{(n-1)s^2}{\chi^2_{\alpha/2}}\right)$, $df=n-1$ | `stats.chi2.ppf(0.975, n-1)` и `stats.chi2.ppf(0.025, n-1)` |
| критерий согласия $\chi^2$ | $\chi^2=\sum\dfrac{(O-E)^2}{E}$, $df=k-1-(\text{число оценённых параметров})$ | `stats.chisquare(f_obs, f_exp)` |
| ANOVA | см. раздел недели 9 | `stats.f_oneway(*groups)` |

## Шаблон вывода

> $z=\ldots$ (или $t=\ldots$), p-value $=\ldots$ (меньше / не меньше) $\alpha=0.05$, значит $H_0$ (отвергаем / не отвергаем): *что именно изменилось, в какую сторону и на сколько* (эффект в п.п. или единицах измерения).

## Ловушки

| Ловушка | Правило |
|---|---|
| p-value двустороннего теста | ×2 и `abs(z)` |
| `sf` или `cdf` | $H_1:>$ → `sf`, $H_1:<$ → `cdf` |
| $z$ или $t$ | σ не дана → t с $df=n-1$ |
| $\sigma$ и $\sigma^2$ | в SE стоит $\sigma/\sqrt n$; дана дисперсия — берём корень |
| `ddof=1` | $s$ считать с `ddof=1` |
| объединённая доля | только в SE теста; в ДИ своя |
| $n$ | всегда вверх (`np.ceil`) |
| п.п. и % | $p_B-p_A$ и $p_B/p_A-1$ — разные числа; знак важен |
| «не отвергаем» | не «доказали, что равны» |
| значимость | статистическая значимость не равна практической важности |

# Неделя 9. Множественное тестирование

| Тема | Что запомнить |
|---|---|
| A/A-тест | значимых различий быть не должно, доля p < α ≈ 5%; сильно больше — сплитование сломано |
| разбиение по чётности id | ломает FPR (id несут информацию) |
| хеширование | `int(hashlib.md5((str(id)+salt).encode()).hexdigest(), 16) % k` |
| соль | делает разбиения независимыми |

| Метод | Правило | Пример (m = 5, α = 0.05) |
|---|---|---|
| FWER | 1 − (1 − α)^m | 0.2262 |
| Бонферрони | α/m | 0.01 |
| Бонферрони точная | 1 − (1 − α)^(1/m) | 0.0102 |
| Холм | p по возрастанию, k-е сравнить с α/(m−k), остановиться на первом непрошедшем | мощнее Бонферрони |
| ANOVA | `stats.f_oneway(*groups)`; H₀: все средние равны; критическое `f.ppf(1-α, k-1, N-k)` | не показывает, какая группа отличается |

## Как проверять сплит-систему и читать множественные сравнения (по ДЗ)

| Ситуация | Что делать и как читать |
|---|---|
| проверка способа разбиения | A/A-тест: Z-тест долей между группами; значимая разница ($p<0.05$) браковала способ |
| группы выглядят одинаково по средним | этого мало: проверить, не связан ли id с метрикой (конверсия по децилям id, по последней цифре) |
| разбиение по медиане id | делит по признаку, связанному с поведением клиента → группы разные по составу |
| разбиение по последней цифре | может не дать перекоса, но случайность не гарантирована |
| хеширование (MD5 + соль) | перемешивает id, группы случайные: лучший способ |
| очистка выборки | убрать тех, кто не подходит под условие (например, уже ездил): иначе они искажают группы, и скрытый перекос может проявиться только после очистки |
| сколько парных сравнений при $k$ группах | $\binom{k}{2}$: 4 группы → 6 пар |
| порог в каждой паре (Бонферрони) | $\alpha/m$: $0.05/6\approx0.0083$ |
| как делать | `ttest_ind(a, b, equal_var=False)` для каждой пары (`itertools.combinations`), сравнить p-value с $\alpha/m$ |
| ANOVA | `stats.f_oneway(*groups)`; $F<1$ — различий между группами нет; значимый $F$ говорит «где-то есть различие», но не где |
| согласованность | если ANOVA не значима, ни одна пара по Бонферрони обычно тоже не значима |
