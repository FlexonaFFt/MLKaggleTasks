Executive Summary

  • The dataset is sequence-first, not row-first. Train contains 773 horizontal wells with 5 092 255 horizontal rows. Validation should be grouped by well_id.
  • The target is TVT continuation. The submission rows are exactly the public test rows where TVT_input is missing.
  • Train has extra geology surfaces that public test does not expose. Treat ANCC, ASTNU, ASTNL, EGFDU, EGFDL, and BUDA as diagnostic context unless they are reconstructed for test.
  • GR coverage is incomplete. Train horizontal TVT_input missingness is 74.3%, and GR also has material missingness.

Recommended next steps

  1. Build a no-ML baseline that extends the last known TVT_input by local slope.
  2. Build a tabular baseline using only test-available fields.
  3. Validate by held-out wells, not random rows.
  4. Add typewell alignment features after the baseline is stable.
