# LLM Classification Finetuning

Baseline pipeline for an LLM classification competition.

## Status

Baseline Python pipeline with supporting notebooks.

- `pipeline.py` - main pipeline.
- `OwnDataLoader.py` - data loading utilities.
- `mlcore/LogReg_model.py` - baseline model code.
- `notebooks/solution.ipynb` - Kaggle-style notebook solution.
- `datascreen/eda.ipynb` - quick data inspection.
