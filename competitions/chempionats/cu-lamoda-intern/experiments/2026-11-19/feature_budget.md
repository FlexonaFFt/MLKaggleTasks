# Размер набора признаков

Для быстрых локальных экспериментов используем 350 признаков по gain LightGBM, рассчитанному заново на обучающих месяцах. На временных срезах разница с полным набором составила +0,00112 AP@20% в феврале и −0,00097 в марте в среднем по трём seed. Для финального ансамбля текущий выбор — полный набор.
