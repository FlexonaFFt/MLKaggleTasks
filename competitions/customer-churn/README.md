# Customer Churn

Binary classification solution for telecom customer churn prediction.

## Status

Pipeline plus research and EDA reports.

## What to Review

- `train_models.py` - main training script.
- `pipeline.ipynb` - end-to-end notebook workflow.
- `research_report.md` - modeling research and approach notes.
- `data_report.md` - dataset diagnostics and EDA summary.
- `model_results.json` - recorded model metrics.

## Data

Expected local data is stored in `dataset/` and is ignored by git. Run scripts
from this folder so relative paths continue to work.
